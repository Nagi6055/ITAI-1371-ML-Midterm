# ITAI-1371-ML-Midterm
dataset choice:Telco Customer Churn

https://www.kaggle.com/datasets/blastchar/telco-customer-churn

This repository holds midterm assignment grabbing a dataset from Kaggle that has a dataset.

This project will mainly focus on the prediction of the customer churns in the
telecommunications area using the machine learning methods that we have learned.
The dataset will have data information of the telecommunication customers and the type of
services that they have received, showing from the demographics and all the information
and services they have gotten.

## Project Objective 

The objective of this project is to clean, explore, and preprocess the dataset and then use
machine learning type of models to help the database using what we learned in the past
labs.

  - Being able to accurately predict the churn to identify the customers who could
leave and grow some retention for the customers information.
  - Target = churn

Seeing the dataset, it has categories and numerical values that could be used in a
machine learning problem, but also can implement class balancing, scaling, and even
encoding. There could be possibly more methods since machine learning has many
possibilities.

Along with this comparing into the real world there will always be some sort of
customer retention problems in the business field that can be affecting in any dataset.
